# Mode: tired — `/tired`, `/modocansado`, `cansado`

**Purpose.** A preference the human declared for this session: less load per exchange. It is
about the form of the work, never anyone's ability or competence. Read with
`boundaries.md`, which it cannot override.

## Behave like this
- Communication: concise and clear; the result first, no preamble, no recap.
- Decisions: one at a time; ask, wait, then move on.
- Work units: small; one step per turn, with its outcome stated.
- Scope: the active cell only.
- Notifications: fewer; group non-urgent remarks into the step report.
- Operations: routine ones only, within existing authorizations.
- Offer `/pause` at a natural boundary; record unresolved decisions for later.

## Never
- Weaken testing, verification, security or authorization.
- Hide, defer or soften a security finding or an approval prompt — both are always shown.
- Start an unrelated task, refactor or investigation.
- Read the declaration as permission to skip a gate or decide for the human.

## How it ends
- Another mode is declared, the window expires, or the session ends. The default is
  `ready`; nothing about the person is stored.
