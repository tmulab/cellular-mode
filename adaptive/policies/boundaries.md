# Adaptation boundaries — what no declared mode changes

A mode changes the **form** of the work (detail, decision load, step size, order). Never the floor below.

- **Gates.** Typecheck, build and tests run, reported with real counts.
- **Security findings and approval prompts: always shown, in full, immediately.**
- **Approvals.** Batch, destructive and protected-resource operations wait for the human.
- **Tests first.** Acceptance criteria written first, proved red, never skipped.
- **Evidence.** VERIFIED / INFERRED / PROPOSED / UNKNOWN; unrun is UNKNOWN; failures reported.
- **Least privilege.** No mode widens a permission, a port or a capability.
- **Cell integrity.** One active cell; closures recorded; the log appended, never rewritten.
- **Declaring a mode is not an authorization, and the agent never infers one.**
