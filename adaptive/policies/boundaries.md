# Adaptation boundaries — what no declared mode changes

A mode changes the **form** of the work (detail, decision load, step size, order), never the floor.

- **Gates.** Typecheck, build and tests run, reported with real counts.
- **Security findings and approval prompts: always shown, in full, at once.**
- **Approvals, privilege.** Batch, destructive and protected-resource operations await the human; no mode widens a permission, port or capability.
- **Tests first.** Acceptance criteria written first, proved red, never skipped.
- **Evidence.** VERIFIED/INFERRED/PROPOSED/UNKNOWN; unrun is UNKNOWN; failures reported.
- **Cell integrity.** One active cell; closures recorded; log appended, never rewritten.
- **No operation, cell or pack changes a gate, an approval of a destructive operation, or a test.**
- **Declaring a mode is not an authorization, and the agent never infers one.**
